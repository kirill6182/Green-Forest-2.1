Обновление «Мои цели» для AI Calorie Tracker

Что изменено:
- На главном экране появилась карточка «Моя цель» с кнопкой настройки.
- Расчёт калорий и КБЖУ учитывает пол, возраст, рост, вес, активность и цель.
- Доступны цели: похудение, поддержание веса, набор массы.
- При сохранении нового веса, если персональный профиль уже настроен, дневные цели пересчитываются автоматически.
- Счётчики калорий и БЖУ остаются на главном экране.

Установка:
1. Распакуйте архив.
2. Замените файлы index.html, app.js, styles.css на GitHub Pages файлами из папки calorie-forest.
3. Остальные файлы (sw.js, manifest.webmanifest, icons) оставьте как есть.
4. Обновите сайт. Если отображается старая версия, закройте приложение и откройте его заново; при необходимости очистите данные сайта/кэш.

Важно:
Расчёт ориентировочный и предназначен для взрослых. Это не медицинская рекомендация и не подходит для беременности, несовершеннолетних и лечебного питания.
